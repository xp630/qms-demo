# 电商平台数据档案 - 设计文档

## 1. 概述

**所属模块：** M08 一体化闭环处置平台
**路由：** `/m08/ecommerce-archive`
**功能定位：** 展示天猫、京东等传统电商平台的账号监测数据档案，支持筛选、详情查看和新建专题

## 3. 数据模型

### 3.1 筛选条件

| 字段 | 类型 | 说明 |
|------|------|------|
| platform | Select | 平台（天猫/京东/淘宝/拼多多/全部） |
| dateRange | DateRangePicker | 时间范围（近7天/近30天/自定义） |
| violationType | Select | 违规类型（假酒销售/虚假宣传/侵权行为/价格违规/全部） |

### 3.2 统计指标卡

| 字段 | 说明 |
|------|------|
| totalAccounts | 账号总数 |
| monitoredAccounts | 监测账号数 |
| violationAccounts | 违规账号数 |
| processingAccounts | 处置中账号数 |

### 3.3 表格列

| 字段 | 说明 |
|------|------|
| accountName | 账号名称 |
| platform | 平台 |
| violationType | 违规类型 |
| violationCount | 违规数量 |
| monitorTime | 最后监测时间 |
| status | 状态（pending/processing/completed） |
| action | 操作（详情） |

### 3.4 状态枚举

- `pending` — 待处置（橙色）
- `processing` — 处理中（蓝色）
- `completed` — 已完成（绿色）

## 4. 组件清单

| 组件 | 来源 | 说明 |
|------|------|------|
| FilterForm | 业务组件 | 筛选表单，平台+时间+违规类型 |
| StatisticCards | 业务组件 | 4个指标统计卡片 |
| ArchiveTable | 业务组件 | 数据表格，含分页 |
| DetailModal | Ant Design | 数据详情弹窗 |
| CreateTopicModal | Ant Design | 新建专题弹窗 |

## 5. 路由集成

页面作为 M08 的子路由：

```
/m08                    → M08Index（工单看板/工单列表/闭环流程）
/m08/ecommerce-archive  → 电商平台数据档案（新页面）
/m08/live-archive       → 直播数据档案（后续实现）
/m08/instant-archive    → 即售平台数据档案（后续实现）
/m08/fraud-archive      → 虚假招商数据档案（后续实现）
```

## 6. Mock 数据

使用 Mock.js 生成 50 条假数据，字段参考 `m08Workorders.ts` 现有模式。

## 7. 技术实现

- **前端框架：** React 18 + TypeScript + Vite
- **UI 库：** Ant Design 5
- **路由：** React Router DOM 6（子路由）
- **数据：** Mock.js（与 M08 现有方式一致）
- **主题：** 沿用现有深色主题（#1A1A2E）
